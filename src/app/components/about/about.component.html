About

Employee Management application

What is this?

A simple application to view and manage employee records. Employees can be browsed as a table or as a list, searched, sorted, and (with the right access) added, edited or deleted.

Roles and access

  • Admin – full access, and can manage other users' permissions.
  • Users – can view employees. Add, edit and delete are available only when the admin grants them.

Disclaimers

This application is a demo. All data, including user accounts, passwords and employee records, is stored in your browser only and is not sent to any server. Passwords are not encrypted and access rules are enforced in the browser, so this app must not be used for real or sensitive data. Clearing your browser data will remove all saved information.
