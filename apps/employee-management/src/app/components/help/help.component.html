Help

A quick tour of the main parts of the application.

1. Login and Sign up

Create an account on the Sign up page, then log in with your email and password. Sessions expire after 10 minutes, after which you will need to log in again.

2. Employee Table

Shows all employees in a table. Use the search box to filter by name or department, and click the Age heading to sort. Users with the right permissions also see the Add Employee button and the Edit and Delete buttons on each row.

3. Employee List

A list of employee names on the left. Click a name to see that employee's details on the right. You can search by name or ID.

4. Add / Edit Employee

Fill in the form and press Save. This is only available if the admin has given you the Add or Edit permission.

5. Settings, Theme and Profile

Use the sun/moon button to switch between Day and Dusk themes, the gear icon for Help, About and (admin only) Access Management, and the profile icon to view your details or log out.

Need more access?

New accounts can view employees only. If you need to add, edit or delete employees, please ask an administrator to update your access.
